## 1. Общие положения

Настоящая политика описывает, как приложение AI Resume Reviewer («Приложение») обрабатывает информацию при его использовании. Устанавливая и используя Приложение, вы соглашаетесь с условиями этой политики.

Приложение помогает анализировать текст резюме с помощью технологий искусственного интеллекта и даёт рекомендации по его улучшению.

## 2. Какие данные мы обрабатываем

Приложение не требует регистрации и не запрашивает ваше имя, телефон, адрес электронной почты или иные персональные данные для работы.

Единственные данные, которые вы передаёте Приложению, это текст резюме, который вы добавляете для анализа.

## 3. Обезличивание данных

Перед отправкой текста резюме на сервер для анализа AI Resume Reviewer автоматически обезличивает его: из текста удаляются данные, по которым можно установить вашу личность (например, имя, телефон, адрес электронной почты, ссылки на профили в социальных сетях [⚠️ уточните список по коду]).

На сервер передаётся только обезличенный текст. Оригинальный текст с вашими данными не покидает ваше устройство.

Несмотря на автоматическое обезличивание, мы рекомендуем не добавлять в текст резюме лишнюю конфиденциальную информацию (например, паспортные данные или номера документов).

## 4. Передача данных на сервер и третьим лицам

Обезличенный текст резюме передаётся по защищённому соединению (HTTPS) на сервер для анализа с помощью ИИ. Обработка может выполняться сторонним поставщиком ИИ-сервисов, который действует как наш подрядчик и обрабатывает данные только для выдачи результата анализа.

Мы не продаём и не передаём данные третьим лицам в рекламных или маркетинговых целях.

## 5. Хранение данных

- Обезличенный текст резюме не сохраняется на нашем сервере и используется только для формирования ответа.
- Результаты анализа хранятся только на вашем устройстве.
- Удалить данные, сохранённые в AI Resume Reviewer, можно, очистив данные приложения в настройках Android или удалив Приложение.

## 6. Аналитика, реклама и сторонние SDK

- AI Resume Reviewer не использует рекламу, аналитику и сторонние SDK, собирающие данные о пользователях.

## 7. Разрешения Приложения

Для работы AI Resume Reviewer требуется доступ в интернет, чтобы отправить обезличенный текст на анализ и получить результат. В приложении используется выбор файла резюме. Других разрешений Приложение не запрашивает.

## 8. Безопасность

Мы применяем разумные меры защиты: шифрование при передаче данных (HTTPS) и обезличивание текста перед отправкой. Однако ни один способ передачи данных через интернет не может быть абсолютно безопасным.

## 9. Дети

AI Resume Reviewer не предназначен для детей младше 13 лет, и мы сознательно не собираем данные детей.

## 10. Ваши права

Вы вправе запросить информацию об обработке ваших данных, их исправление или удаление. Поскольку AI Resume Reviewer не собирает идентифицирующие данные, мы можем быть не в состоянии связать запрос с конкретным пользователем. По любым вопросам пишите на anton.kichiy.dev@gmail.com
